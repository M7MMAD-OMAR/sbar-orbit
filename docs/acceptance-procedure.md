# Real application acceptance procedure

Updated 22 October 2026.

Choose an implemented adapter from [the platform matrix](support-tiers.md).
Record source and loaded-plugin identities, original registration, numbered
workspace, owner authorization, actual geometry and exact cleanup. Verify a real
content change, native input, capture, pointer visibility, focus behavior and
handback separately. File workflows need save and independent byte verification.

Check the actual plugin source and compositor ABI. The historical incident hold
is retired; [the incident record](native-handoff-incident.md) is evidence, not a
current prohibition. Preserve owner work, inspect uncertain delivery and never
relaunch blindly. Missing phases remain not measured. See
[current acceptance](acceptance.md).
