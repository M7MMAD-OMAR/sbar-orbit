# Real application acceptance procedure

Updated 22 October 2026.

Choose a supported host from [the platform matrix](support-tiers.md). Record the source identity, application registration, selected workspace, consent, observed window geometry and cleanup. For application work, separately prove an actual content change, save and reopen, input delivery, capture permission, pointer visibility, focus behavior and handback. The [input hold](native-handoff-incident.md) must not be bypassed to run this procedure. Missing phases stay not measured.
