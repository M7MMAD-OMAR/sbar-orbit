# Application files

Updated 22 October 2026.

Orbit uses original applications and ordinary owner files. It creates no cloned
HOME or private document namespace. Native Text Editor Save through the system
portal and independent byte reads are measured in
[current acceptance](native-acceptance-0.3.0.md). This does not certify every
application's file workflow. Direct filesystem work is separate from native UI.

Parent-linked cross-client dialogs stay with the controlled workspace. They need
a separate exact handoff, restricted to the selected dialog family. Other dialogs
of the shared service are preserved. Hand a portal back promptly after use.
See [handoff](existing-application-handoff.md) and [the contract](desktop-only.md).
