Exact window identity was address `0x561cab924a00`, stable ID `180000d6`, PID 330835.

The experiment created only `/tmp/orbit-issue26-20261105/coordinate-target`, navigated the new window to its parent using Ctrl+L, text and Return, then observed the tree and capture. The target cell was `[194,43,112,119]`, giving center `(250,102.5)`. Two native clicks at that center returned two receipts.
