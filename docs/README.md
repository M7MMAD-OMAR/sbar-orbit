# Orbit native desktop documentation

Orbit opens and controls original installed applications on explicit visible
numbered workspaces. The implemented native adapter targets Linux Hyprland;
operation-specific application measurements are indexed below. Complete
application and cross-platform compatibility remain unfinished.
