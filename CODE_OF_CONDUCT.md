# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith. Argue with the work, not the person.

## What is expected

- Keep discussion technical and specific. "This is wrong because X returns Y" is useful; "this is
  garbage" is not.
- Accept that a measured result beats an opinion, including yours and including the maintainer's.
- Say when you do not know. An honest "I did not test that" is worth more here than a confident guess,
  and this project's own documentation is written the same way.
- Respect that people give their time. Nobody here owes you a reply, a fix or a feature.

## What is not acceptable

Harassment, personal attacks, discrimination on any ground, sexual attention, deliberate intimidation,
publishing anyone's private information, and sustained disruption of discussion.

## Scope

This applies in the repository's issues, pull requests and discussions, and anywhere someone is
representing the project.

## Reporting

Report a problem privately through a GitHub issue asking for a private channel, with no detail in it,
or through the security contact in [SECURITY.md](SECURITY.md). Reports are handled by the maintainer.
A report is read, and the person who sent it is told what happened with it.

Responses range from a request to change behaviour, to removing comments, to blocking an account,
depending on what happened. Nothing here is automatic and nothing here is negotiable in public.

This is a small project with one maintainer. Where this document is silent, the short version applies.
